## What This Project Is

Fine-tuned MedSAM2 (Hiera-Tiny, 38.9M params) on the ARCADE coronary angiogram dataset for vessel segmentation in X-ray fluoroscopy. The model goes from Dice 0.033 zero-shot to **Dice 0.767 ± 0.082** on ARCADE val (200 images) with a single centroid click prompt.

The goal is edge deployment at clinical sites (limited/outdated hardware) for real-time vessel segmentation and occlusion flagging during angiography procedures.

## Clinical Endpoints

**No teacher retraining needed.** All endpoints are post-processing on the binary vessel mask output by CA-SAM2. Implemented in `endpoints.py`:

| Endpoint | Method | Notes |
|---|---|---|
| Vessel diameter | Distance transform along medial axis skeleton | Per skeleton point |
| Stenosis candidates | Skeleton points where diameter drops >35% below median | Yellow markers in overlay |
| Occlusion candidates | Interior skeleton terminations + isolated fragments | Red markers in overlay |
| Stent candidates | Bright linear structures in raw image overlapping mask (Hough) | Cyan lines in overlay |

**For video:** run per-frame, aggregate across frames (median diameter = stable measurement; occlusion flag fires if gap present in >50% of frames).

## Distillation Pipeline

Two-stage knowledge distillation from CA-SAM2 teacher → lightweight student for edge deployment.

**Students:**
- `MobileSAM` — ViT-Tiny (~6M params), 1024×1024 input, best ONNX/TRT support
- `RepViT-SAM` — RepViT-M1 backbone + SAM decoder (~512×512), faster CPU inference

**Stage 1** (`stage1_softlabels.py`): Teacher runs inference on all 1000 ARCADE train images, saves raw logits as `.npy` to GCS. ~20–30 min on GPU.

**Stage 2** (`distill_student.py`): Student trains with combined KD loss (0.5 × KD_BCE soft labels + 0.4 × hard GT loss + clDice warmup). 30 epochs, batch 16. ~2–4 hrs on P4 GPU.

**Ablation 4** (default, `--ablation 4`) is the full model: KD response + GT + clDice.

## Known Issues & Fixes Applied

| Issue | Fix | Where |
|---|---|---|
| `python: command not found` | Use `python3` throughout | `setup_gcp.sh` |
| Wrong GCS path for arcade val | `datasets/arcade/val/` not `arcade_val/` | `eval_endpoints.py` |

| `KeyError: 'model'` on checkpoint load | Fine-tuned ckpt is raw state dict; `build_sam2` expects `{"model": sd}` — auto-wrap on load | `eval_endpoints.py`, `stage1_softlabels.py` |
| Distill scripts expect raw state dict | Handle both formats: if `{"model": sd}` unwrap before key iteration | `distill_student.py` |
| `torch.autocast("cuda")` crashes on CPU | Guard with `if DEVICE == "cuda"` | `stage1_softlabels.py`, `distill_student.py` |
| `GradScaler("cuda")` crashes on CPU | Add `enabled=(DEVICE == "cuda")` | `distill_student.py` |

| SSH as non-root can't write to `/opt/` (owned by root from startup script) | Use IAP tunneling; write to `/tmp/` for manual ops | Ops note |

## Design Decisions & Tradeoffs (Pre-paper Notes)

### KD method selection for fluoroscopy segmentation

**Decision: Multi-scale feature matching, not attention transfer**

Attention transfer (AT) forces the student to replicate where the teacher "looks" spatially. For this task we have GT masks, which are a strictly better supervision signal for spatial attention than the teacher's attention maps — the teacher is only 0.767 Dice, the mask is ground truth. Mask-guided AT collapses into supervised attention training and the teacher becomes redundant. AT was dropped.

Multi-scale feature matching is irreplaceable because the GT mask tells you *where* vessels are but says nothing about *what features* to produce there. The teacher's intermediate representations encode learned abstractions about coronary anatomy (curvature, branching, contrast gradients) that the mask has no information about. Feature matching weighted by GT foreground mask is the correct combination: teacher provides feature targets, mask focuses the loss on the vessel pixels.

**Decision: Foreground-weighted feature loss, not uniform**
Coronary vessels are ~5% of pixels. Uniform feature matching is 95% background noise. GT mask used as spatial weight concentrates the signal where it matters.

**Noted for later: teacher-free distillation for image-based tasks**
For tasks with rich GT supervision, distillation may add less over direct fine-tuning than assumed. Worth testing once we have the direct fine-tune baseline (ablation=1). Teacher-free feature learning (e.g. MAE-style pretraining on fluoroscopy images) is a longer-term direction — not a current priority.

### Data split decision (v3)
Using the 200 ARCADE val images as both early-stopping signal and test metric is data leakage — early stopping decisions made on the test set inflate reported Dice. Fixed in v3: 900 train / 100 internal val (early stopping only) / 200 ARCADE val (held-out test, never touched during training). Seed=42 for reproducibility.

### Early stopping reliability
100-image val set is too small for a stable signal — val Dice has high variance (0.63–0.70 across epochs) causing early stopping to fire on noise rather than true plateau. Training loss was still decreasing when ES fired at epoch 17. Consider fixed-epoch training or larger val set in future runs.

## Checkpoint Notes

The fine-tuned checkpoint `medsam2_arcade_v2.pt` is saved as a **raw PyTorch state dict** (not wrapped). This causes issues:

- `build_sam2()` (MedSAM2 loader) expects `{"model": state_dict}` → auto-wrap before calling
- `distill_student.py` teacher loader iterates raw keys directly → unwrap if wrapped

Both cases are now handled automatically in the code.
